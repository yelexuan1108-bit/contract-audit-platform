# 成交单审核平台 — 用户指南

一个用于香港投资成交单的 AI 辅助审核平台。平台将成交单与官方模板进行对照，找出缺失或不一致的条款。

## 1. 平台概览

平台支持四种产品：

| 产品 | 页面 | 说明 |
|---|---|---|
| 股票成交单 | Stock | 股票交易；自动识别 HK/US 市场及子类型 |
| 基金成交单 | Fund | 基金交易；自动识别语言 |
| VA 虚拟资产 | VA 虚拟资产 | 虚拟资产成交单；自动识别 Buy/Sale 与语言；额外执行 VA 专项检查 |
| 投资月结单 | Statement | 月结单；3 种子类型：月结单 / BB Invest / 南向通 |

每次审核执行以下检查：

- **条款核查** — 本地规则引擎，将 PDF 提取文本与已保存的条款模板和必填字段进行比对。
- **AI 审核** — 可选的 LLM 复核（仅股票与基金），标记风险发现、费用减免及总结。
- **VA 专项检查** — 虚拟资产成交单专用检查器（50 项）。

## 2. 安装与启动

### 环境要求

- Python 3.10+
- 依赖见 `requirements.txt`

### 安装与运行

```bash
pip install -r requirements.txt
cp .env.example .env   # 然后编辑 .env
python app.py
```

浏览器打开 http://localhost:8000。

### 配置（`.env`）

| 变量 | 用途 | 是否必填 |
|---|---|---|
| `OPENROUTER_API_KEY` | AI 审核（OpenRouter/Claude）的 API Key。不设置则仅运行本地规则引擎。 | 否 |
| `PORT` | 服务端口（默认 `8000`）。 | 否 |

右上角徽标会显示 AI 是否已启用。

## 3. 审核产品

所有产品页（股票 / 基金 / VA / 月结单）流程一致。

### 第 1 步 — 上传文件

- 将**文件夹**或 **PDF 文件**拖入上传区，或点击 **选择 PDF 文件 / 选择文件夹**。
- 支持多文件（单次最多 **200 份**）。
- 文件列表会显示已选文件及总大小。

### 第 2 步 —（仅月结单）选择子类型

在月结单页面选择 **子类型**：投资月结单 / BB Invest / Southbound 南向通。

### 第 3 步 —（仅股票/基金）可选跳过 AI

勾选 **跳过 AI 审核**，仅运行本地规则引擎。大批量跑量时速度更快。

### 第 4 步 — 开始审核

点击 **开始审核**。进度条显示实时上传/处理进度，文件并发处理。

### 第 5 步 — 查看结果

每份文件会标注识别出的产品、子类型及总体结果：

- **条款通过** — 所有条款检查通过。
- **条款问题** — 列出未通过的条款。

展开结果可查看：

- **英文条款 / 中文条款** — 逐条通过/失败及匹配关键词。
- **个人资料** — 个人信息检查。
- **AI 审核** — 发现项、严重/警告/提示数量及总结（股票/基金）。
- **VA 专项检查** — 50 项 VA 清单（VA）。

## 4. 条款模板管理

**条款模板** 页面管理本地规则引擎使用的条款模板。

### 标签页

- **产品标签**：Stock / Fund / VA / Statement。
- **子类型标签**：有子类型的产品会显示（股票 6 种；VA 有买入/卖出；月结单有月结单/BB Invest/南向通）。
- **语言标签**：English / 繁体中文 / 简体中文。

每个产品按子类型与语言分别存储条款，并附带版本号。

### 手动编辑

- 点击 **+ 添加条款** 新增条款，内联编辑后点击 **保存全部条款**。
- 保存时条款编号会自动重新排序。

### 从 HTML 模板导入

三种方式：

1. **单文件导入** — 替换当前产品 + 语言的条款。
2. **批量导入** — 选择多个 HTML 文件；从文件名自动识别语言（`_hk_` / `_zh_`）和子类型（`bbInvest` / `southBound` / 默认 `monthly`），并写入对应位置。
3. **一键同步** — 扫描整个模板文件夹并导入所有 HTML 文件，从路径自动识别产品、子类型与语言。

> 导入后请点击 **保存全部条款**，写入 `data/clauses.json` 生效。

## 8. 常见问题

**问：为什么明明导入了模板，文件仍显示「条款问题」？**
请确认在正确的产品页上传了文件。例如将基金文件上传到 VA 页面会全部失败——应上传到对应产品页。

**问：「跳过 AI 审核」有什么作用？**
关闭 LLM 复核，仅保留快速的本地规则引擎。

**问：上传上限是多少？**
单次最多 200 份 PDF。

**问：没有 API Key 能否使用？**
可以——条款核查与 VA 检查完全离线运行。只有 AI 复核需要 `OPENROUTER_API_KEY`。
